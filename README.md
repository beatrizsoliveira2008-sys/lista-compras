# Lista de Compras Mobile

Aplicação mobile desenvolvida em React Native (Expo) como uma prática guiada para consolidar conceitos fundamentais de desenvolvimento mobile.

## Objetivo
O projeto tem como foco relembrar e exercitar práticas essenciais da criação de interfaces para dispositivos móveis, incluindo:
* Manipulação de estado e hooks (`useState`)
* Componentização e estruturação visual (`View`, `ScrollView`, `Pressable`)
* Estilização com `StyleSheet`
* Integração de fontes customizadas e bibliotecas de ícones (`@expo/vector-icons`)
